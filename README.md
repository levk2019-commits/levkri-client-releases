# LevKri's CLIENT — Windows

Готовые сборки Windows x64 доступны в [Releases](https://github.com/levk2019-commits/levkri-client-releases/releases/latest).

Скачайте `LevKrisClient.exe`. Нужны права администратора для TUN и Microsoft Edge WebView2 Runtime.

Начиная с версии 1.1.0 клиент проверяет подписанные обновления и предлагает установку внутри приложения. Установка требует подтверждения и кратковременно прерывает VPN при перезапуске. Старым версиям без этой функции нужна одна ручная замена EXE.

В релизах нет подписок, личных настроек, логов или ключа подписи. Файл `update.json` содержит подписанную информацию о версии, размере и SHA-256 готового EXE.

Скорость в интерфейсе — текущая передача в Мбит/с, не максимальная скорость канала. Проверка доступа не гарантирует доступность каждого сайта.
